'zyzz-lynx': minor
---

Lynx production builds that compile every module in one graph, such as Rspeedy builds, named generated classes from one dense table in compilation order instead of module-qualified and hashed names. A declaration unit became `z` and a base-36 index, such as `z3` instead of `z_i6Fywm0`, and a recipe's choice-class prefix became `z`, a capital letter counting its digits, and the digits, so a choice class became `zA00` instead of `zvet-RFk250`. `cx` copies of recipe rules rename under the same table. Web builds, development builds, partial graphs, and packed libraries keep their readable names.
