Added the `zyzz/rspeedy` plugin for Lynx applications. It compiles project sources in each Rspeedy environment and serves the combined stylesheet as the `zyzz.css` module, so an entry adds the styles to the Lynx bundle with `import 'zyzz.css'`. The package is now published as `zyzz-lynx`.
